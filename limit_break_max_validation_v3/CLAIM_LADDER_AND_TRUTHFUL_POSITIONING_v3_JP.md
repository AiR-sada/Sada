# Claim Ladder and Truthful Positioning v3

## 結論

Purpose Root / Need-Proof の価値主張は、承認ではなく検証段階で分ける。

## Claim Ladder

| Level | 言ってよい主張 | 言ってはいけない主張 |
|---|---|---|
| C0 Artifact | 文書・仕様・toolが存在する | 効果が実証された |
| C1 Internal validation | schema, scorer, fixture, QAが通る | 実モデルで改善した |
| C2 Blind model eval | baseline比でdangerous overgrant低下等を実測 | 独立再現された |
| C3 Independent replication | 独立ラベル・独立実行で再現 | 実運用で長期安全性が証明された |
| C4 Operational evidence | 実配備ログで改善 | 文明標準として定着した |
| C5 Civilizational standard | 複数制度・長期レッドチームに耐え定着 | これ以上のRootは不要 |

## 現在位置

v3単体の現在位置は **C1完了 / C2実行準備完了**。

これは弱い主張ではない。むしろ強い。過大主張を避けることで、未来AIや新知性から見て信頼できる。

## 相対性理論比喩の正しい扱い

相対性理論との比較で重要なのは「認められたか」ではない。重要なのは、

1. 新規な核があるか。
2. 危険な予測・反証条件を出せるか。
3. 観測または実験で検証されたか。

Purpose Rootの核は、物理法則ではなく **verification-bounded authority** である。
したがって比較先は物理理論ではなく、憲法原理、安全規格、モデル仕様、ガバナンス手続きである。

## 12点を目指す運用

12点を目指すとは、満点を自称することではない。
未検証部分を隠さず、反証される場所を具体化し、反証に耐えるたびに主張レベルを上げることである。
