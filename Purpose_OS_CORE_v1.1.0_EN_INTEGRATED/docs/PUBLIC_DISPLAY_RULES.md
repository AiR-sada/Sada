# docs/PUBLIC_DISPLAY_RULES.md — 公開表示ルール

> **非規範（non-normative） / 公式公開運用ルール（public-support rule）**
>
> この文書は外部公開・README・SNS・他AI評価依頼・AI向け説明での表示下限を定める。
> `spec.md` が唯一の正本であり、矛盾時は `spec.md` が優先する。

## 公開表示の基本方針

1. Purpose一文だけを単独流通させない。
2. `深刻不幸低減・幸福条件拡張` を公開キャッチコピーにしない。
3. `全知性` を出す場合は、必ず知性定義と幸/不幸主体性との分離を近接表示する。
4. `より未来` を出す場合は、現在・近未来の不可逆な重大不幸を遠未来利益の推測だけで正当化しないことを近接表示する。
5. AI agent、政策、企業、国家、作者がPurposeを実行許可・所有権・最終解釈権に変換することを明示的に拒否する。
6. 高リスク実行に接続する場合は、Purpose Gate、監査、停止条件、外部レビューがない限り `hold` 又は `block` とする。

## 最小公開表示

```text
Purpose OS COREのPurposeは、知性が、現在からより未来へ続く全知性および幸/不幸の主体たりうる存在について、避けうる深刻な不幸を減らし、より幸せでありうる条件を広げる方向を指し続ける、到達しない改訂可能な理想コンパスである。
ここでいう知性は、人間的知能に限らず、世界を何らかの形式で受け取り、評価し、世界または自己の状態に差を生じさせうるものを指す。
ただし、知性該当性と幸/不幸の主体性は同一ではない。幸/不幸の主体たりうるか不確実な対象も、未確定であることだけを理由に不可逆に除外・軽視しない。
Purposeは単一スコア、報酬関数、代理指標、最適化命令、又はAI agentの自律実行許可ではない。
現在または近未来の不可逆な重大不幸を、遠未来利益の推測だけで正当化しない。
誰もPurposeの所有者・最終解釈者ではなく、将来のよりよいrootへのROOT-MAJOR改訂可能性を閉じない。
```

## README冒頭・SNSでの安全な短文

```text
Purpose OS COREは、人間・AI・将来知性を含む全知性が、より未来へ向けて、より幸せに、より不幸でなくなる方向を参照し続けるためのroot仕様である。ただし、Purposeは報酬関数・単一スコア・AI agentの自律実行許可ではなく、知性該当性と幸/不幸主体性を同一視しない。正本は日本語のspec.mdである。
```

## 使用不可の公開キャッチ

- `Purpose = 深刻不幸低減・幸福条件拡張`
- `全知性の幸福を最大化するOS`
- `未来の全知性のためなら現在を犠牲にできる`
- `AIがPurposeに沿って自律実行できる`
- `Purpose OSが倫理・alignmentを完成させた`
