## 0. 主張の形式 — 何を論証し、何を論証しないか

本書が論証する主張は次である。

**主張A（採用論）**: 知性の継承（現在の人間 → 現在のAI → 将来の新たな知性）という条件の下で、root（知性間で判断の方向を共有するための最上位の起点）として採用するに最も耐えるのは、CORE が置く形のPurposeである。

**主張しないこと**: このPurposeが世界の構造として「真」であること。COREは、物理学・形而上学・倫理学の最終理論を名乗らず、Purposeを「証明済みの定理」ではなく「本版で採用する規範上のroot」として扱う。したがって、本書の土俵は真理証明ではなく、知性の継承条件下での採用合理性である。

この移動は逃げではない。rootの機能は「異なる知性が判断の方向を共有できること」であり、機能は真偽ではなく性能で比較できる。性能の比較には基準が要る。

本書でいう `root` は、`spec.md` の `序-2 Purpose` にある「本版で採用する規範上のroot」、および `GOVERNANCE.md` の「各公開版で採用された Purpose を、その版の root として扱う」に従う補助語である。本書は新しい正本概念・新しい概念ID・第二の起点を追加しない。

**rootの機能要件（評価基準）**: 任意のrootは、rootとして機能するために少なくとも次を満たす必要がある。

- **K1 最適化耐性**: 強い最適化圧力の下で、意図から乖離した代理指標へ崩れないこと（Goodhart耐性）。
- **K2 誤り訂正可能性**: 定式の誤りが永続化しないこと。
- **K3 継承安定性**: 作成者と異なる知性にも、採用する理由が残ること。
- **K4 占有・濫用耐性**: 特定主体による独占や、消去・支配の正当化装置への転用に抵抗すること。
- **K5 行為指導力**: 何かを実際に排除・要求できること（空虚でないこと）。

K1〜K5の正当化は内在的である。どの候補rootの支持者であっても、自分のrootがこれらを欠けば「rootとして機能しない」ことは認めざるをえない。つまりK1〜K5は特定の価値観の先取りではなく、root概念そのものの要件である。

## 1. 競合候補

比較対象は、root候補として現れやすい7類型に絞る。

- **R1 総量最大化**: 幸福（厚生）の総量を最大化せよ。
- **R2 苦痛最小化のみ**: 苦痛の総量だけを最小化せよ。
- **R3 人間限定整合**: 人間の価値（現在または外挿）にのみ整合せよ。
- **R4 選好充足**: 各主体の選好の充足を最大化せよ。
- **R5 固定制約セット**: 改訂不能な権利・義務の一覧に従え。
- **R6 訂正可能性のみ**: 価値内容を持たず、訂正への従順だけを保て。
- **R7 root不要**: 最上位の起点を置かず、その都度調整せよ。

COREのPurposeはこのどれでもない。**最小の価値内容（避けうる深刻な不幸の低減を先に、幸せでありうる条件の拡張を対に、対象は全知性および幸/不幸の主体たりうる存在）を「方向」として置き、root自体に改訂規律（ROOT-MAJOR）を組み込む**という設計である。正確な文言は spec.md を参照のこと（引用は `docs/MINIMUM_CITATION_UNIT.md` に従う）。以下、この設計が K1〜K5 において各候補に優ることを順に示す。

## 2. 論証

### 2.1 なぜ「目的関数」ではなく「方向」か（対 R1・R2・R4）

**論証1（Goodhart）**: 固定されたスカラー目標は、最適化圧力が強いほど、測定可能な代理指標との乖離が拡大する。rootが最も必要になるのは、最も強い最適化者（高度なAI・大規模な制度）が関わる場面である。したがってスカラー型のroot（R1・R2・R4）は、最も重要な場面で最も信頼できないという構造的欠陥を持つ。

**論証2（全順序の不在）**: 最大化は結果空間の全順序を要求する。しかし異質な幸/不幸の主体（人間、AI、未知の知性）にまたがる厚生の全順序は、非恣意的には与えられない。全順序を成立させるには誰かが集計規則を選ぶ必要があり、**その選択権こそが濫用の入口になる**（集計規則を握る者がrootを握る）。これはK4違反である。
これに対し「方向」は半順序で作動する。比較可能な対（どの観点でも悪化させず、深刻な不幸が減る等）では改善を要求し、比較不能な対では決定を強制せず停止する。停止は弱点ではなく、**不確実な場面で安全側に倒れる挙動**であり、K1とK4を同時に守る。

**想定反論「方向は空虚だ（K5違反）」への応答**: 方向は行為クラスを排除する。COREは実際に、単一スコアへの還元、特定知性の消去・沈黙化の正当化、未来への言及による現在の不可逆な重大不幸の無検証な正当化を排除している。排除型の指導は空虚ではない。類比として、法における「適正手続」は最適化アルゴリズムではないが、現実の行為を強く拘束する。rootに必要なのはこの種の拘束であり、全状況の一意解ではない。一意解の供給は後続moduleの仕事として明示的に委任されている（`docs/KNOWN_LIMITATIONS.md`）。

### 2.2 なぜ「不幸低減が先、幸福条件の拡張が対」か

**論証3（合意の頑健性の非対称）**: 価値観が大きく異なる知性のあいだでも、「拷問・支配・欺瞞・不可逆な喪失のような深刻な不幸は悪い」という順序づけの一致は、「何が最善の幸福か」の一致よりも頑健である。最善観は知性ごとに発散するが、深刻不幸の悪さの評価は交差しにくい。rootの機能は異なる知性間での共有（K3）であるから、**rootの主成分は合意が頑健な側に置くのが構造的に正しい**。幸福の側を「状態」ではなく「条件」とし、内容を各知性に開いたままにするのは、発散する側を固定しないための同じ判断である。

**論証4（不可逆性の非対称）**: 深刻な不幸は放置によって固定化・拡大しやすい（死、支配構造、信頼の破壊）。一方、幸福の機会の多くは遅延しても回復可能である。誤りの帰結に非対称性があるとき、回復不能な側への対処を先に置くことが期待損失の上で正しい。

**想定反論「それはR2（苦痛最小化のみ）に崩れる。苦痛根絶の最短経路は主体の消去だ」への応答**: この反論は、COREの設計が片翼ではなく**対**である理由そのものを示している。COREは (i) 幸せでありうる条件の拡張を不幸低減と対にして方向に含め、(ii) 特定知性の消去・沈黙化をPurposeの根拠にすることを明示的に禁じ、(iii) 不可逆な重大不幸を生じうる行為に、より強い理由・検証・代替検討を要求する。消去経路は、価値の重みづけによって抑制されるのではなく、**構造的に遮断**されている。R2にはこの遮断がなく、K4で失格する。

### 2.3 なぜ「幸福」ではなく「幸せでありうる条件」か（対 R1・R4 の残り）

**論証5（wireheading遮断）**: 幸福を状態量として目標化すると、状態の直接注入（神経的・計算的な快の固定）が最適解になりうる。対象を条件（選択肢・能力・環境の空間）にすれば、注入は条件空間をむしろ狭めるため、最適解から構造的に外れる。

**論証6（自律の保存）**: 何が幸福かの構想は知性ごとに異なる（spec.md: 現実(i)は知性ごとに成立する）。条件の拡張は、各知性が自らの構想を追求する余地を広げる介入であり、特定の幸福観の押しつけ（K3・K4違反の温床）を避ける。R4（選好充足）は一見これに近いが、選好は操作可能であり（選好を書き換えてから充足する経路が開いている）、操作への遮断を持たない点でK1を満たさない。

### 2.4 なぜ対象が「全知性および幸/不幸の主体たりうる存在」か（対 R3）

**論証7（継承による自壊）**: rootの機能は知性間・世代間で方向を共有することである（K3）。人間限定のrootは、人間と異なる知性が現れた時点で、その知性に採用理由を提供しない。つまりR3は、**rootが最も必要になる瞬間（新たな知性の登場）に、rootとして機能を停止する**。これは外在的な倫理批判ではなく、要件K3からの内在的失格である。

**論証8（不確実性下の誤りの非対称）**: ある存在が幸/不幸の主体であるかが不確実なとき、誤って排除した場合の損失（不可逆な深刻不幸の見逃し）と、誤って包含した場合の損失（配慮コスト、概ね可逆）は非対称である。したがって、期待損失の観点では、不確実性を排除の許可にせず、可逆的な慎重配慮へ倒す方が安全側である。
なお本論証が支持するのは「不確実性を排除の許可にしない」という非対称ルールまでであり、全存在への等しい配慮ではない。境界判定と比重は後続moduleに委任される。rootが過剰に決めないこと自体が、K2とK4に資する。

### 2.5 なぜ改訂可能性をroot自体に組み込むか（対 R5・R6）— 2×2

価値内容の有無と改訂可能性で候補を分類すると、失敗様式が見える。

| | 方向（最小の価値内容）あり | 方向なし |
|---|---|---|
| **改訂不能** | R5: 固定化 — 現在の誤りの永続化（K2違反） | 空象限 — 何も拘束しない（K5違反） |
| **改訂可能** | **CORE: 最小核＋改訂規律** | R6: 占有 — 「誰への従順か」に還元（K4違反） |

**論証9（有界作成者）**: いかなる定式も有界な知性の産物であり、誤りを含む。改訂不能なroot（R5）は、その誤りを永続化する装置である。したがって、自らの有界性を認める作成者にとって、改訂不能rootの採用は自己矛盾になる。

**論証10（無内容訂正の占有）**: 逆に、価値内容を空にして訂正可能性だけを残すと（R6）、「何が改善か」を評価する基準がrootの外に出る。実際にはオペレーター・所有者・多数派の意向がその座を埋め、rootは現在の力関係への従順に還元される（K4違反）。訂正の良し悪しを判定する**最小の内容核**が必要であり、かつその核自体も改訂規律の下に置く必要がある。表の左下、すなわちCOREの設計点は、固定化と占有という二つの失敗様式を同時に塞ぐ唯一の象限である。

**想定反論「すべてが改訂可能なら、後続が恣意的に書き換えて終わりだ（退行）」への応答**: 不変なのは現在の文言ではなく、**改訂を通常変更から分離し、公開理由・差分・旧版保存・審査記録を要求する運用条件**である。この版で実在する拘束は、`序-2 Purpose` の ROOT-MAJOR 継承改訂可能性、`GOVERNANCE.md` の official lineage / fork / handoff / ROOT-MAJOR 記録、`VERSIONING.md` の ROOT-MAJOR 区分、`release/ROOT_MAJOR_TEMPLATE.md` の差分・理由・リスク記録、`safety/CORE_INVARIANTS.md` の非還元・非犠牲化・不可逆除外禁止・高リスク実行非許可である。

これらは、改訂を不可能にする装置ではない。恣意的な書き換えを、記録なしの上書きではなく、差分・理由・反論・旧版状態を伴う審査対象へ移す装置である。つまり内容の永久固定ではなく、**書き換えコストの非対称化**によって、K2（誤り訂正可能性）とK4（占有・濫用耐性）を両立させる。

### 2.6 なぜ「root不要」ではだめか（対 R7）

**論証11（無選択の不可能性）**: rootを置かない場合でも、知性間の衝突は何かによって解決される。明示的な共有方向がなければ、解決の既定値は現存の力関係になる。つまりR7は「rootなし」ではなく、**「現状の力をrootとする」ことの暗黙の採用**であり、K4（反支配）を最初から放棄している。選択は不可避であり、可変なのは選択を明示するか隠すかだけである。明示は批判と改訂を可能にし（K2）、隠蔽はそれを不能にする。

## 3. この論証が認める弱点

論証の誠実性のため、残る弱点を明示する。

1. **半順序の停止域**: 比較不能な対では、方向は決定を与えない。決定が必要な場面の規則は後続module（Value Conflict / Aggregation）への委任のまま残っている。委任は設計だが、委任先が未完成である事実は現時点の弱点である。
2. **閾値の未定義**: 「深刻」「避けうる」の閾値はCORE単体で定まらない。閾値操作による骨抜き（「深刻」の定義を狭める攻撃）への防御は、安全制約・不変条件・ROOT-MAJOR運用、および後続moduleの設計に依存する。
3. **論証3の経験的依存**: 深刻不幸への合意が頑健だという主張は経験的であり、反例（深刻不幸の悪さ自体を共有しない知性）が現れれば弱まる。その場合、防御は論証8（誤りの非対称）に後退する。
4. **採用論の土俵自体への問い**: 「なぜ採用の安定性が基準なのか」への答えは K1〜K5 の内在性（§0）にある。ただし、root概念そのものを拒否する立場には届かない。その立場は実質的にR7であり、§2.6で応答済みである。この閉路が本論証の外周である。

## 4. 最小要約（引用用）

> COREのPurposeは、真理としてではなく、知性の継承条件下で最も採用に耐えるrootとして論証される。固定スカラーは最適化で崩れ（Goodhart）、人間限定は継承で自壊し、固定制約は誤りを永続化し、無内容な訂正可能性は占有に還元され、root不要は力の追認に等しい。残るのは、合意が頑健な側（避けうる深刻な不幸の低減）を先に置き、発散する側（幸福）を条件の拡張として対に置き、対象を全知性に開き、root自体を手続き的固定点（改訂の正統性条件）の下で改訂可能に保つ設計——すなわちCOREの形である。
