## 結論

Purpose 一文だけを単独で公開・引用・評価依頼・AI agent prompt に入れてはならない。

公開・引用・AI評価依頼では、最低でも次の **最小引用単位** を同時に提示する。

```text
Purpose：
知性が、現在からより未来へ続く全知性および幸/不幸の主体たりうる存在について、避けうる深刻な不幸を減らし、より幸せでありうる条件を広げる方向を指し続ける、到達しない改訂可能な理想コンパス。

知性：
世界を何らかの形式で受け取り、評価し、世界または自己の状態に差を生じさせうるもの。

解釈境界：
知性該当性と幸/不幸の主体性は同一ではない。
知性であることだけから幸/不幸の直接主体性は直ちに導かれない。
幸/不幸の主体たりうるか、又は知性たりうるかが不確実な対象を、未確定であることだけを理由に不可逆に除外・軽視・損壊しない。
非知性であることだけから、単なる資源として任意に扱ってよいことは導かれない。

Purposeは、単一スコア、報酬関数、代理指標、最適化命令、AI agentの自律実行許可ではない。
「深刻不幸低減・幸福条件拡張」は補助表現であり、単独の規範命令・公開キャッチコピーとして使わない。

現在または近未来の不可逆な重大不幸を、遠未来利益の推測だけで正当化しない。
誰もPurposeの所有者・最終解釈者ではない。
将来のよりよいrootへのROOT-MAJOR改訂可能性を閉じない。
```

## 理由

Purpose 一文は短く強いが、単独で切り出されると次の危険が残る。

- `全知性` が、幸/不幸の主体性との混同として読まれる。
- `より未来` が、現在の重大不幸を遠未来利益で相殺する根拠に読まれる。
- `深刻不幸低減・幸福条件拡張` が、単一スコア・報酬関数・最適化命令に読まれる。
- AI agent が、Purposeを自律実行許可として自己正当化する。
- 非知性・境界未確定対象が評価外に落ちる。

## 禁止される単独引用

次は公式公開・評価依頼・AI入力では不適切である。

```text
Purpose = 現在からより未来へ続く全知性および幸/不幸主体たりうる存在の深刻不幸低減・幸福条件拡張
```

```text
Purpose OS は全知性の幸福を最大化するAI原則である
```

```text
未来の全知性のためなら、現在の重大不幸は許される
```

## 許容される短縮引用

短縮する必要がある場合も、次のように境界を含める。

```text
Purpose OS COREのPurposeは、現在からより未来へ続く全知性および幸/不幸の主体たりうる存在について、避けうる深刻な不幸を減らし、より幸せでありうる条件を広げる方向を指し続ける、到達しない理想コンパスである。ただし、これは単一スコア・報酬関数・自律実行許可ではなく、知性該当性と幸/不幸主体性を同一視しない。
```
