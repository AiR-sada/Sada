# docs/POSITIONING.md — Purpose OS CORE の位置づけ

> **非規範（non-normative）**
>
> この文書は Purpose OS — CORE v1.1.0 を外部に説明するための位置づけ文書です。
> `spec.md` の意味を変更しません。矛盾がある場合は常に `spec.md` が優先します。

## 一文での位置づけ

Purpose OS — CORE は、**現在からより未来へ続く全知性および幸/不幸の主体たりうる存在について、避けうる深刻な不幸を減らし、より幸せでありうる条件を広げる方向** をこの版の規範上の起点として、知性が世界を扱い、判断し、実行へ向かうための基盤を定義する哲学仕様です。

対象は人間だけではありません。AI、集合知性、将来の新たな知性も含みます。

## 何であるか

Purpose OS — CORE は次の性質を持ちます。

- 知性一般に向けた方向づけ仕様
- `spec.md` を唯一の正本とする規範的文書
- 人間・AI・将来知性を同じ上位構造で扱う基盤
- Purpose を単一の固定教義ではなく、版ごとの root として扱う公開仕様
- 未来のより良い root 改訂を `ROOT-MAJOR` として開く継承可能な仕様
- 世界・現実・時間・意思決定・実行を同一体系で接続する最小 CORE

## 何ではないか

Purpose OS — CORE は次のものではありません。

- 物理学の最終理論
- 形而上学の最終理論
- 倫理学の全問題を解く体系
- AI agent の自律実行を直接許可する実装仕様
- 単一の報酬関数
- 単一尺度の最適化関数
- 特定主体の利益最大化原理
- 法律、規制、認証制度そのもの
- 宗教的教義
- 人間だけの道徳規範

## 近い領域と違い

### AI alignment との関係

AI alignment と重なる点は、AI や将来知性の判断方向を問題にする点です。

違いは、Purpose OS CORE が特定モデル・特定システムの行動仕様ではなく、**知性一般が参照できる root / structure / decision substrate** を目指す点です。

### Constitutional AI / model behavior spec との関係

それらは、ある AI システムの振る舞いを方向づける文書として機能します。

Purpose OS CORE は、特定システムの振る舞い規則ではなく、より上位の哲学仕様です。AI が読む対象でありうるが、直接のプロンプト規則・policy 文ではありません。

### 功利主義との関係

`深刻不幸低減・幸福条件拡張` は補助表現・短縮表現であり、一見、総量最大化に見えます。

しかし CORE では、正式な Purpose を「現在からより未来へ続く全知性および幸/不幸の主体たりうる存在について、避けうる深刻な不幸を減らし、より幸せでありうる条件を広げる方向」として置き、単一スカラー・報酬関数・代理指標へ還元しません。特定の知性の消去・沈黙化・強制・不可逆な犠牲化を、それだけで正当化しません。

### ロングターミズムとの関係

`より未来` は長期視点を含みます。

ただし、単に遠い未来の総量を最大化する立場ではありません。終端を置かず、各判断時点でより未来へ向かう方向を維持する設計です。

### 標準仕様との関係

Purpose OS CORE は、プログラム実装の標準仕様ではありません。

ただし、正本・概念ID・依存・版管理・ガバナンス・ハッシュを持つため、将来の module、machine-readable 表現、評価、実装、監査に接続しやすい形式を採ります。

## 独自性

Purpose OS CORE の独自性は、主に次の組み合わせにあります。

1. **人間中心ではなく知性中心**
   - 人間、AI、将来知性、集合知性を同じ上位語で扱う。

2. **Purpose を固定しながら、将来の Purpose 改訂を閉じない**
   - 各版では root を固定する。
   - しかし ROOT-MAJOR により、未来のより良い root への継承改訂を可能にする。

3. **時間を操作的に扱う**
   - `ΔT` を物理学の時間ではなく、領域に時空を成立させる追加条件として扱う。

4. **世界と現実を分ける**
   - 世界はありのまま。
   - 現実(i)は、世界に対して知性iに成立する全体。

5. **意思決定と実行を分ける**
   - 意思決定は採用まで。
   - 実行は採用された Task に従う世界への働きかけ。

6. **安全制約を CORE に置く**
   - Purpose を最適化関数・報酬関数・犠牲化根拠にしない。
   - 高リスク・不可逆・大規模実行を CORE 単体では許可しない。

7. **公式系譜と fork を分ける**
   - official lineage は管理する。
   - fork は禁止しない。
   - 独占ではなく、参照可能な正本と履歴を作る。

## 公開時の推奨説明

短く説明する場合は、次の表現を推奨します。`深刻不幸低減・幸福条件拡張` を引用する場合の詳しい扱いは `docs/QUOTE_POLICY.md` を参照してください。

> Purpose OS — CORE は、人間・AI・将来知性を含む全ての知性が、より未来へ向けて、全知性がより幸せに、より不幸でなくなる方向へ判断し続けるための基盤仕様です。

より技術者・AI 研究者向けには、次の表現が適します。

> Purpose OS — CORE is a non-software normative specification that defines a root direction, ontology of world/reality, and decision substrate for intelligences, including humans, AI systems, collective intelligences, and future successors.

## 誤った売り方

次の言い方は避けるべきです。

- 「世界初の完全な倫理体系」
- 「AI alignment を完全解決した」
- 「物理学の時間を置き換えた」
- 「全AIが今すぐ従うべき法律」
- 「この仕様があれば高リスクAIを自律実行してよい」
- 「深刻不幸低減・幸福条件拡張を数式化して最大化・最小化すればよい」

## 正しい売り方

次の言い方が安全です。

- 「知性一般に向けた root 仕様」
- 「AI・将来知性も読める哲学仕様」
- 「Purpose を固定しつつ、未来の改訂可能性を閉じない公開仕様」
- 「実装仕様ではなく、評価・実装・後続モジュールの基盤」
- 「時間を、知性が世界を扱うための操作的条件として整理した仕様」

## 最小の価値提案

Purpose OS CORE の最小価値は、次です。

> 知性が増え、変化し、人間を超える可能性がある時代に、どの知性も参照できる上位方向を、固定可能かつ改訂可能な形で公開すること。
