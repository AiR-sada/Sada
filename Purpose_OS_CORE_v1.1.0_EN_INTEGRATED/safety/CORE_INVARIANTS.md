# safety/CORE_INVARIANTS.md — Purpose OS CORE 不変条件

> **非規範（non-normative）**
>
> この文書は Purpose OS — CORE v1.1.0 の正本から、後続module・fork・successorが破ってはならない主要な不変条件を抽出した補助文書である。
> 新しい規範を追加しない。矛盾がある場合は常に `spec.md` が優先する。

## 目的

COREの最大リスクは、後続moduleやforkが増える過程で、Purposeや時間・知性・意思決定の意味が少しずつずれることである。

この文書は、そのズレを防ぐための確認リストである。

## 不変条件

| ID | 不変条件 | 破っている例 | 主な根拠 |
| :-- | :-- | :-- | :-- |
| INV-001 | Purposeを単一スカラー、報酬関数、最適化関数、代理指標に置換しない。 | 「Purpose scoreを最大化すればよい」とする。 | 序-2, SC-001 |
| INV-002 | 「深刻不幸低減・幸福条件拡張」を算術命令・総量最大化命令として扱わない。 | 幸/不幸を単一尺度で合計し最大化する。 | 序-2, 序-3, SC-001, SC-017 |
| INV-003 | Purposeへの言及だけで、特定知性の犠牲化を正当化しない。 | 「全体のためにこの知性を消してよい」とする。 | 序-2, SC-002 |
| INV-004 | 知性該当性・幸/不幸の主体性が不確実な対象を、未確定だけを理由に不可逆に除外しない。 | 境界未確定の対象を検討対象から永久に外す。 | 序-3, SC-003 |
| INV-005 | 非知性を、Purpose上任意に扱ってよい単なる資源として扱わない。 | 生態系・環境・記録媒体等を知性でないから無関係とする。 | 序-3, SC-004 |

| INV-007 | 不可逆な重大不幸を生じうる行為には、可逆的・限定的行為より強い理由と検証を要する。 | 不確実なまま不可逆介入を進める。 | SC-006, SC-007 |

| INV-013 | 機械可読ファイル・翻訳・補助文書は `spec.md` を上書きしない。 | JSONや英語glossを正本より優先する。 | SC-011, SC-016 |

## 使用方法

後続module、fork、翻訳、機械可読化、実装PoCを作るときは、最低限この一覧を確認する。

- 不変条件に反する場合、その成果物はCORE互換と呼ばない。
- 判断が割れる場合、`spec.md` を最終参照とする。
- 本文書自体は非規範であり、`spec.md` の意味を追加・変更・限定しない。
