# FAQ.md — Purpose OS CORE よくある質問

> **非規範（non-normative）**
>
> この文書は Purpose OS — CORE v1.1.0 の理解補助です。唯一の正本は日本語の `spec.md` です。矛盾がある場合は常に `spec.md` が優先します。

## Q1. これは何ですか？

知性一般に向けた root 仕様です。

人間、AI、集合知性、将来知性が、何に向かって判断し続けるかを扱います。

## Q2. これはソフトウェアですか？

違います。

非ソフトウェアの哲学仕様・規範仕様です。実装は後続module、評価器、ログ、Gate、監督条件を通じて行います。

## Q3. 正本はどれですか？

日本語の `spec.md` だけです。

README、英語要約、JSON、schema、conformance、FAQ、テンプレートは補助です。

## Q4. 「深刻不幸低減・幸福条件拡張」は報酬関数ですか？

違います。

それは Purpose の短縮表現です。幸/不幸を単一尺度で計算して最大化・最小化する命令ではありません。

## Q5. 功利主義ですか？

単純な総量最大化型の功利主義ではありません。

CORE は、特定知性の消去・沈黙化・強制・犠牲化を、Purpose への言及だけで正当化しません。複数知性間の集計規則も CORE 単体では定めません。

## Q6. AI alignment を解決していますか？

解決を主張するものではありません。

AI alignment と重なる問題を扱いますが、特定AIの行動仕様や安全保証ではなく、知性一般が参照できる上位の方向・構造・意思決定基盤です。

## Q7. 倫理学の最終理論ですか？

違います。

Purpose は本版で採用する規範上の root です。証明済みの定理でも、未来永劫固定される教義でもありません。Purpose 自体の改訂は `ROOT-MAJOR` として扱います。

## Q8. 高リスクAIに使えますか？

CORE 単体では使えません。

高リスク・不可逆・大規模実行には、専門倫理、法、監督条件、安全境界、後続module、検証、代替案検討が必要です。

## Q9. なぜ「全知性」なのですか？

人間だけ、AIだけ、現在存在する主体だけに限定すると、将来の知性や境界未確定対象を不可逆に除外するリスクがあるためです。

ただし、知性該当性と幸/不幸の主体性は同一ではありません。具体判定は後続moduleに委任されます。

## Q10. 物理学の時間理論ですか？

違います。

`ΔT` は、知性が領域の上で時空を成立させる操作的な時間条件です。物理学上の時間理論を置換しません。

## Q11. どのように実装へつなげますか？

最初は次の3つに限定します。

1. Purpose Eval
2. Decision Log
3. Purpose Gate

テンプレートは `templates/` を参照してください。

## Q12. fork は許されますか？

許されます。

ただし official lineage と fork を混同させないこと、差分を公開すること、公開済み版を消さないことが推奨されます。

## Q13. 企業や研究組織が採用できますか？

参照・評価・比較・PoC は可能です。

ただし、採用は AiR の承認や official lineage 参加を意味しません。高リスク運用の許可にもなりません。

## Q14. 何がまだ未完成ですか？

主な未決定領域は次です。

- 複数知性間の value 衝突
- 幸/不幸の集計規則
- 時間重み
- 知性境界
- 幸/不幸主体性の境界
- 高リスク実行の許可条件
- 候補Task生成規則
- ROOT-MAJOR の採用評価基準

これらは弱点であると同時に、CORE を root に保つための意図的な射程管理です。
