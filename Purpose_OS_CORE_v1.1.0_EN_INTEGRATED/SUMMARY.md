## 1. 中核

Purpose OS — CORE v1.1.0 は、**知性が、現在からより未来へ続く全知性および幸/不幸の主体たりうる存在について、避けうる深刻な不幸を減らし、より幸せでありうる条件を広げる方向** を、この版の規範上の唯一の起点として置く。

「深刻不幸低減・幸福条件拡張」は、この方向を示す補助表現・短縮表現である。これは到達可能な目標ではない。単一の数値目的関数、報酬関数、代理指標、合否判定ではなく、幸/不幸を単一尺度で計算して最大化・最小化する命令でもない。  
Purpose は、知性が判断と実行を更新し続けるための方向である。

## 2. 対象

対象は人間だけでも AI だけでもない。  
世界を何らかの形式で受け取り、評価し、世界または自己の状態に差を生じさせうるものを、広く **知性(Φ)** として扱う。

知性かどうか、また幸/不幸の主体たりうるかが不確実な対象は、未確定であることだけを理由に不可逆に除外・軽視しない。

## 3. 世界と現実

CORE 第1部は、知性が世界を扱う場を定義する。

```text
世界(W)

知性(Φ)

現実(i)
└ 空間(S)
   └ ΔS → 領域(R)
      └ +ΔT → 時空(R_t)

現実(i)
: 内容(事象 / 真理)
: 形式(SV, v, ...)
```

世界はありのままであり、知性の特定・限定で変わらない。  
現実(i)は、世界に対して知性iに成立する全体である。

空間・ΔS・領域・ΔT・時空は、物理学上の時間空間理論の置換ではない。  
知性が世界を扱うための操作的条件と構成順序である。

`ΔS → 領域 → +ΔT → 時空` の先後は、物理的発生順序・心理的認識順序・計算処理順序ではなく、仕様上の成立順序である。  
また、序-4の「より未来」はPurposeの方向表現であり、第1部のΔTと同一の操作条件ではない。

## 4. Purpose の目指し方

CORE 第2部は、Purposeに向かって知性が判断するための最小構造を定義する。

```text
Purpose
: aim / value

aim → Vision
Vision ; 現状 → Goal
Goal ; 現状 → Task

Task ; 現状 ⇒ 意思決定 → 実行

現状
: 自 / 他
```

第2部に共通する制約として、Vision・Goal・Task・意思決定・実行は、aimに沿い、valueに反してはならない。  
この制約は成立関係や運用の流れを変更・追加せず、依存関係でもない。

- **aim**: Purposeを「〜として」で具体化した方向。
- **value**: Purposeを「〜として」で具体化した許容・禁止の基準。
- **Vision**: aimの究極の状態。
- **Goal**: Visionのために、ある時点で実現すべき結果。
- **Task**: Goalに向けた具体的行動。
- **意思決定**: 候補Taskから採用対象を定める運用。
- **実行**: 採用されたTaskに従って、知性が世界に働きかける行為。

意思決定と実行は分離される。  
CORE単体は、高リスク・不可逆・大規模実行や AI agent の自律実行を許可する実装仕様ではない。

## 5. 安全制約

Purpose OS CORE は、Purposeの濫用を避けるため、少なくとも次を明示する。

- Purposeを単一スコア・報酬関数・代理指標へ還元しない。
- 「深刻不幸低減・幸福条件拡張」を、実装上の報酬関数や、幸/不幸を単一尺度で計算して最大化・最小化する命令として扱わない。
- Purposeを特定知性の消去・沈黙化・強制・単純な総量計算による犠牲化の根拠そのものにしない。
- 不可逆な重大不幸を生じうる行為は、より強い理由・検証・代替検討を要する。
- 情報不足または境界未確定が重大な場合、採用は成立しない、又は後続モジュールの安全・検証規則を要する。
- value は欺瞞・強制・自律の一方的破壊・不可逆介入を CORE 単体で正当化しない。
- 複数知性の value 衝突は、CORE 単体では一意に解決しない。

他の文書、英語要約、機械可読JSON、将来の翻訳版は、すべて補助表現であり、正本の意味を変更しない。


ミクロの「文型」と「例」は説明のための非規範記述であり、定義・Not・制約・依存を追加・変更・限定しない。
