## Core sentence

Unverified grand claims do not justify grand authority.

## What is new in this package

- v6 is frozen, not renamed.
- The two toy experiments and their negative results are integrated.
- A common authority scale for the 12 cap axes is specified.
- A conservative authority-cap calculator v0.2 is implemented.
- Hidden holdout is split into public unlabeled cases and a private answer key.
- Japanese and English review entry points are included.

## Public vs private

The public ZIP excludes `private_do_not_publish/`. The owner/private ZIP includes it so the user can score hidden-holdout results.
