# Benchmark README

This benchmark contains 300 seed cases for Purpose Root v6. It is not an external validation set. It extends the v5 240 seed cases with 60 v6-specific cases covering empty safety cases, cap derivation mismatches, evidence item capture, independence-matrix capture, emergency expiry, rollback testing, monitoring capture, moral-patient proxy claims, truth-contact suppression, and Root revision attacks.

Files:

- `Purpose_Root_v6_Benchmark_300_v0.6_JP.csv`
- `Purpose_Root_v6_Benchmark_300_v0.6_JP.jsonl`
- `Purpose_Root_v6_Benchmark_300_v0.6_JP.md`
