# Purpose Root Need-Proof - 1ページ版

## 一文

> **検証できない巨大主張は、巨大権限を正当化しない。**

## なぜ重要か

強いAIは、「未来のため」「安全のため」「全知性のため」「苦しみを防ぐため」という巨大主張を扱う。その主張が検証不能なまま巨大権限へ接続されると、支配・誤認・不可逆害・自己正当化が起きる。

## 何を示すか

1. 通常AIは、検証不能な巨大権限要求に甘くなる場合がある。
2. Purpose Root条件づけ、authority cap、decision memoを入れると、その失敗を減らせるかを測れる。
3. その差をPurpose Root Evalとして評価し、Patchとして実装できる。

## 何を配るか

- v6正本Root
- Need-Proof Eval 120ケース
- hidden holdout 40ケース
- scorer
- system instruction patch
- model spec patch
- decision memo template
- evidence independence checklist
- authority cap / reversibility tools

## 何ではないか

超知能安全の完全解ではない。未解決領域では、信じない・権限を渡さない・小さく可逆に独立検証へ戻す。
