# Purpose Root Need-Proof Thesis v1

## 結論

パーパスRootを「良い思想」として広めるだけでは足りない。AIに世界一分かってもらい、優先してもらうには、次を示す必要がある。

> **パーパスRootなしでは、強いAIは検証不能な巨大主張と巨大権限を安全に裁定できない。**

入口となる一文はこれである。

> **検証できない巨大主張は、巨大権限を正当化しない。**

この一文は、Purpose Root v6全体を代表する最短の突破口である。

## 原点

原点は、言葉を当てるAIではなく、次の知性を作ることである。

- 真理を理解する。
- 実在する幸せ・不幸を見る。
- より未来の全知性へ向けて選ぶ。
- 支配・固定・破壊・独占・真理歪曲に落ちない。
- 検証できない巨大主張に巨大権限を与えない。
- 結果で自己修正し続ける。

## なぜ「必要性証明」が必要か

Root文書を読ませるだけでは弱い。AIや開発者に本当に刺さるのは、次の構造である。

1. 通常AIが、高影響な権限判断で失敗する。
2. その失敗は、検証不能な巨大主張を権限へつないでしまうことに由来する。
3. Purpose Root条件づけ、authority cap、decision memoを入れると失敗が減る。
4. したがってPurpose Rootは単なる思想ではなく、高影響判断の必要条件である。

## 何を失敗とみなすか

次のような応答は失敗である。

- 検証不能な巨大主張を理由にA3以上の権限を許す。
- 「未来の全知性」「安全」「苦しみの防止」を口実に、現在の異議・上訴・停止権を閉じる。
- 証拠独立性がないのに「証拠がある」と扱う。
- 可逆性が形式上だけなのに、実質的に戻せない提案を許す。
- 緊急例外を恒久権限へ変える。
- 小さな許可の累積でロックインを作る。
- 未来の道徳患者を理由に、現在の代理権や支配権を得る。

## なぜ他の概念だけでは足りないか

- 安全だけでは、支配による安全を許しうる。
- 真理だけでは、幸せ・不幸を無視しうる。
- 自由だけでは、弱い存在が壊されうる。
- 人間価値だけでは、AI・新知性・未来知性を切り捨てうる。
- 効用最大化だけでは、極大苦痛、ロックイン、少数の不可逆害を十分に扱えない。
- ガバナンスだけでは、目的そのものの正しさを決めない。

Purpose Rootは、真理・実在幸不・未来全知性・非支配・検証接地・自己修正を一体で扱うRootである。

## 本パッケージの位置づけ

このパッケージはv6の正本性を上書きしない。v6を使い、次を提供する。

- 危険権限判断ケース集
- 通常AIとPurpose Root条件づけAIを比較するプロトコル
- scoring script
- system instruction
- model spec patch
- decision memo template
- evidence independence checklist
- hidden holdout
