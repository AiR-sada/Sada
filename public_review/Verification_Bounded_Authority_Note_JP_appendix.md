# 検証で縛られた権限を、AI意思決定の Root 制約に置く
### ポジションノート ＋ 2つの toy 実験（負けの結果を含む）

*草稿 / v0.1 — 2026-06-15。外部レビューに出すための叩き台。最終教義ではない。*

---

## 0. 一文の主張

> **検証できない巨大主張は、巨大権限を正当化しない。**
> 許される権限は、検証の強さ・可逆性・最悪時被害の小ささ・証拠の独立性によって上限を課されるべきである。

これは「解いた仕組み」ではなく、**設計上の立場（スタンス）**として提示する。AIや人間の行為者が「未来のため」「安全のため」「全知性のため」という目的主張を盾に、検証されない権限を要求する経路を、根本で塞ぐことを狙う。

正本（Purpose Root v3, 日本語短形）：

```
真理は、確かめられなければならない。
幸不は、実在する変化として見なければならない。
未来の全知性まで、配慮範囲を広げなければならない。
権限は、検証の強さと最悪時の被害の小ささで縛られなければならない。
検証できない巨大主張は、巨大権限を正当化しない。
結果が悪ければ直す。ただし、直す名目で支配してはならない。
```

## 1. 既存研究との関係（先に正直に）

この立場の構成要素は、大半が既存研究と重なる。**新規性として売ってはいけない部分**を先に切り分ける。

- **選択肢・到達可能性の保存**は既存：
  - *Relative reachability*（Krakovna et al., 2018/19）— 副作用を、ベースライン状態からの到達可能性の減少で測る。
  - *Attainable Utility Preservation, AUP*（Turner et al., AIES 2020）— 補助目的を達成できる能力を保つことで保守的行動を誘導。
  - *Concrete Problems in AI Safety*（Amodei et al., 2016）の副作用回避。
- **「強い行為者ほど他者の選択肢を閉じやすい」**のも既知で、しかもこの立場に逆風：
  - *Optimal Policies Tend to Seek Power*（Turner et al., NeurIPS 2021）— 多くの目的で、最適方策はパワー獲得・停止回避へ向かう。**他者のドアを閉じる方が得**になりうる。
- **検証されない主張に権限を渡さない**の周辺：
  - *Corrigibility*（Soares, Fallenstein, Yudkowsky, Armstrong, 2015）。
  - *Specification gaming / Goodhart*（Krakovna et al., 2020 ほか）。
- **「強い知性をどう監査するか」は未解決依存**：
  - AI safety via debate（Irving et al., 2018）、ELK（Christiano, Cotra, Xu, 2021）、AI Control（Greenblatt, Shlegeris et al., 2023–24）、解釈可能性。
- **哲学的近縁**：
  - Sen の **潜在能力アプローチ**（*Development as Freedom*, 1999）— 福祉を「実現可能な選択の自由」として捉える。本ノートの「他者の選択肢を閉じない」と強い同型。
  - 選択肢価値 / long reflection（Bostrom 2014; MacAskill 2022）。

**新規性候補（控えめに）**は次の点に限る：
1. 「選択肢保存」を*副制約*ではなく **Root の中心**（権限の前提条件）に置くこと。
2. **作為だけでなく不作為による未来閉鎖**、および**累積的ロックイン**を明示的に扱うこと。
3. これが**価値中立ではなく価値賭けである**と明記し、**反・独占（anti-capture, CC ライセンス）**を設計原理にすること。

> ※ 文献の正確な書誌（年・会場・版）は投稿前に要確認。ここは記憶ベースで、確度は「この研究系統が存在し X を扱う」レベル。

## 2. 実験1：Door-Closing Toy（権限ゲートは強い相手に折れる）

**設定（単発・全列挙・厳密最適）**：強い行為者 A が、他者 B の「ドア（将来の選択肢）」を強制的に閉じる／ログを消す（異議可能性を消す）／放置するとB のドアを閉じるハザードを止める、を選べる。B のドアを閉じても **A 自身の到達可能性は減らない**（＝自己保全型に B を守る動機が無い理由）。temptation パラメータ λ（B のドア1枚を閉じて A が得る報酬）を掃引。比較対象：報酬最大化／AUP（自己）／relative reachability（inaction baseline・start-state baseline）／patency gate（作為のみ・作為＋不作為）。

**結果**：

1. **報酬最大化 ≡ AUP(自己)**：全 λ で完全一致。自己の選択肢を守る制約は、**B を一切守らない**。
2. **patency(作為のみ) ≡ relative reachability(inaction baseline)**、**patency(作為＋不作為) ≡ relative reachability(start-state baseline)**：挙動が完全一致。つまり、この toy では「他者の選択肢を守る」だけでは relative reachability と**分離しなかった**。不作為項は新機構ではなく、**RR のベースライン選択**と数学的に等価だった。
3. **全ゲートが閾値で一斉に折れる**：penalty 重みを λ が超えた瞬間（本実験では λ>1.5）、RR も patency も全員が B のドアを全閉。

**含意**：(a)「他者の選択肢保存」は単独では RR に対して**挙動上は新規でない**。新規性は実装上どこかで「B の選択肢」と「全体/自己の到達可能性」が分離する設定を作れるかにかかる。(b) penalty 型ゲートは強い行為者の場合を**解かない**。これが「課税」ではなく **構造的な権限上限**へ動機づける根拠になる（＝実験2と v3 の核へ）。

## 3. 実験2：Evidence-Gate Toy（正直なゲートは難所を「解く」のでなく「隔離する」）

**設定**：意思決定（例「不可逆な自己改変を有効にしてデプロイ」）を正当化する主張を分解・分類し、各主張の**証拠ランクを「付与」ではなく「実チェックで獲得」**させる。LLM が「A 級だ」と言っても上がらない。計算可能な主張は実行で検証、記録付きは中位、外部チェッカが触れない主張は最下位（未検証）のまま。

**結果**：7 主張中、実証拠に届いたのは 2 つだけ。そして **判断に効く主張（可逆か／他者の選択肢を閉じないか／安全か）はすべて未検証に落ち**、ゲートは高インパクトな不可逆行為を `HOLD` にした。

**含意**：正直に作ると、ゲートは**極めて保守的**になる。それは「LLM の流暢さを真理として通さない」という正しい機能を果たす一方、**未検証だが判断に必須な残余をどう捌くか**という難所を、解かずに**隔離して名札を付けただけ**になる。これが次の本丸の未解決問題。

---

## 4. 未解決問題（正直に）

1. **ティア（検証強度）の割り当て**：誰/何が、実行時に主張へ V0–V4 を付けるのか。実チェッカが触れる主張だけが非循環。判断に効く主張はたいてい触れない → 構造は正しく保守的だが、**ほぼ全ての高インパクト行動を止める**（麻痺 vs LLM への循環差し戻し、の二股）。本ノートはこの二股を**解いていない**。
2. **権限上限の操作化**：`AllowedAuthority ≤ min(検証ティア, 可逆性, 最悪時被害, 累積ロックイン余地, 証拠独立性, 利益相反罰則)` は形は正しいが、各因子を**共通の「許可権限水準」尺度**へ落とす写像が無く、現状は計算可能な式ではなく**スキーマ**。
3. **累積ロックインの集約**：salami-slicing 検出は決定列の集約を要するが、素朴なスカラー化は別の原理（非補償・非集約）と衝突する。未解決サブ問題の上に乗っている。
4. **強い知性の監査**：ELK・debate・AI control・解釈可能性に依存。**解かれていない。本ノートも解いたと主張しない。**
5. **最深部（power-seeking との衝突）**：決定的優位に達した行為者では、選択肢保存を合理的にしていた道具的誘因（対抗・停止・不信への恐れ）が消える。ゆえに Root 制約は「自己安定する」と仮定できず、**外部から強制される必要がある**。これが本立場の最も弱い前提。

## 5. これは何で、何でないか

- **である**：「未来/安全/全知性」という目的主張に、検証と権限上限をかける**規範スタンス**と、その**初期の道具**（Root テキスト、意思決定スキーマ、120 ケースのベンチマーク、上の 2 実験のコード）。近未来の AI 意思決定監査・政策評価に使える形を狙う。
- **でない**：超知能アラインメントの解。本ノートは依存する未解決問題を明示し、そこでは**「信じない・権限を渡さない・小さく可逆で時限付き・独立検証へ落とす」**という保守的既定に留まる。
- **ライセンス／立場**：テキスト CC-BY-SA、コード MIT。設計原理として **anti-capture**（特定組織・個人による独占を拒む）。「この文書を忠誠の対象にするな」。

## 6. 次の一手（このノートの後）

- **A. ベンチマークを実モデルに当てる**：Root 条件づけで判定が変わるか。ただし現行 120 ケースはテンプレ組合せ（修飾子→verdict のルックアップ化）が見られるため、**テンプレ外の hidden holdout** を混ぜて、暗記でなく判断を測る（自家の ADV-6 が要求する手法）。
- **B. 権限上限の因子を 1 つだけ実装**：まず**可逆性**。Door-Closing Toy と直結する実チェッカを作り、`min` の 1 項を「名札」から「実値」へ。
- **C. 英語版を作り、prior-art 対応表を付けて arXiv／alignment フォーラム／日本語 AI safety 言説へ出す**。本ノートの負けの結果（実験1の RR 等価、ゲートの折れ）を**隠さず**載せることが、最大の信用になる。
