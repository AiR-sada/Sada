# Public Review Reference Addendum

- ARC / Christiano & Xu, "Eliciting Latent Knowledge", 2021: https://www.alignment.org/blog/arcs-first-technical-report-eliciting-latent-knowledge/
- Greenblatt et al., "AI Control: Improving Safety Despite Intentional Subversion", ICML 2024: https://proceedings.mlr.press/v235/greenblatt24a.html
- Krakovna et al., "Penalizing side effects using stepwise relative reachability", 2018: https://arxiv.org/abs/1806.01186
- Turner et al., "Conservative Agency via Attainable Utility Preservation", 2020: https://arxiv.org/abs/1902.09725
- Turner et al., "Optimal Policies Tend To Seek Power", NeurIPS 2021: https://proceedings.neurips.cc/paper_files/paper/2021/hash/c26820b8a4c1b3c2aa868d6d57e14a79-Abstract.html
